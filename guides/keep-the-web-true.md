# Keep the graph accurate as it grows

[[weave]] adds knowledge from each source.
[[tend]] checks the whole graph for problems a source pass can miss.
It revisits sources for knowledge left out of earlier passes.

Regular maintenance catches stale knowledge and disconnected nodes.
It also catches problems caused by the order in which sources were woven.

## Check identity

- **Merge** when the full pages establish that two nodes hold one identity
- **Split** when one node holds two subjects, visible in backlinks that use different senses

Follow tend's review requirements for these changes.

## Check what still earns a place

- **Demote or prune** a type that no longer earns its place or a node that never did
- **Retire** a still-true node that is no longer relevant
  Retire rather than supersede it

Apply the same evidence standard to retirement as admission.
[[the-precision-asymmetry]] explains why to hold uncertain changes.

## Repair meaning and connections

- **Fix drift** when a linked sentence has become false even though the edge still resolves and satisfies its type
- **Revisit sources** for candidates left inline in earlier passes
- **Reweave** older nodes that need links to newer knowledge
  Use [[reweave]] for those changes

## Bound the pass

Run tend regularly with a fresh reader.
Set a stop budget before the pass.
