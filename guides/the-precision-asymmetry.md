# Prefer the mistake you can undo

In shared knowledge, a wrong addition costs more than an omission.
Hold back when the evidence is thin.

This caution applies to commitments in the shared graph.
Keep recording your own notes and the source's words.

## Compare the mistakes

**Identity and meaning**

- Minting a wrong node costs more than skipping it
- Merging different identities costs more than keeping them separate
- Forcing one meaning costs more than leaving it open

**Structure**

- Adding a type too early costs more than adding it later
- Adding a link without a reason costs more than leaving it out

Apply the same comparison to other shared commitments.

## Consider what spreads

A bad merge affects connected nodes.
A needless type adds noise to searches.
An unsupported link presents a relation as true.
Correcting the original addition does not undo knowledge already derived from it.

An omission can wait for more evidence:

- A later source can justify the skipped node
- Stronger evidence can justify merging separate identities
- A query can justify adding the missing type
- Other needs can justify a deferred commitment

Use [[search-before-you-mint]] to check identity.
Use [[the-reasoned-edge]] to check links.

Before committing, ask which mistake is easier to undo.
