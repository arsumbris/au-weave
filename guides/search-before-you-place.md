# Search before you place

Search for every map a node belongs on before placing it.
Each map covers a slice of the graph.
Judge membership by the node's meaning.

[[search-before-you-mint]] finds the identity a mention names.
Placement finds the maps that should include that identity.

## Look beyond existing links

Following a node's links finds nearby knowledge.
It can miss a sibling map the node belongs on.
Coverage from one map leaves that omission hidden.
A reader on the missing map still cannot find the node.

Use meaning to check both directions:

- Add a membership the links missed
- Withhold a membership the links suggest when the node does not belong

A false membership presents the wrong classification as true.
Apply [[the-precision-asymmetry]] to each placement.

## Revisit maps as the graph grows

[[reweave]] places a node on maps its meaning earns, including those its links never reach.
When [[tend]] creates a map, it checks older nodes for membership too.

Name the maps the node belongs on.
Compare them with the maps its links reach.
Place the node on each appropriate map.
Explain the placement in that map's form, following [[the-reasoned-edge]].
