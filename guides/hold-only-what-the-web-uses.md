# Hold only what the web uses

A node earns its place through the knowledge or reasoning it contributes.
Being true or named in a source is not enough.

This guide applies to the shipped [[concept]] and [[claim]] kinds.
Other domains set their admission guidance through the premise and node kinds.

## Distinguish a concept from a claim

A concept defines a meaning other nodes name.
A definition can be used or revised.

A claim states a proposition other nodes reason from or challenge.
Preserve the source's qualifications.
Further sources can add grounds for the claim.

A subject can earn both kinds, as [[one-subject-many-kinds]] explains.
Judge each contribution separately.
Default to one node when a claim only restates a concept.
Fold that restatement into the concept.

## Check what the graph uses

[[mine]] records source-supported candidates within the profile's kinds.
[[cut]] applies the premise and admission guidance.

A claim must pass all three tests:

- **Load-bearing**
  Another node reasons from it or the premise turns on it
- **Contestable**
  A support or challenge edge could bear on it
- **Beyond a definition**
  It asserts something about the world, such as a consequence or cause
  Defining what a concept means is not enough

Name the node that would use the concept.
For a claim, name the reasoning that would use it.
If neither use exists, the candidate earns no node.

## Keep supported disagreements

A contradiction can give the graph an argument it needs to hold.
Conflict alone is no reason to reject a candidate, as [[the-argument-edge]] explains.

When the candidate passes the admission checks, let [[weave]] resolve or mint it.
Draw the edge that explains the disagreement.
The tension must be supported and needed for the graph's reasoning.
Apply [[the-precision-asymmetry]] before treating a difference as an argument.
